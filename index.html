Reconocimiento de Figuras en Grafo

Este sistema modela 6 figuras geométricas representadas en un grafo según sus características (número de aristas) y realiza una búsqueda ciega (BFS y DFS) para identificarlas.

Haz clic en el botón para iniciar la simulación...

Código Python embebido:


# Estructura del Grafo de 6 Figuras
grafo = {
    'Triángulo': {'aristas': 3, 'vecinos': ['Cuadrado', 'Pentágono']},
    'Cuadrado': {'aristas': 4, 'vecinos': ['Triángulo', 'Hexágono']},
    'Pentágono': {'aristas': 5, 'vecinos': ['Triángulo', 'Hexágono']},
    'Hexágono': {'aristas': 6, 'vecinos': ['Cuadrado', 'Pentágono', 'Heptágono']},
    'Heptágono': {'aristas': 7, 'vecinos': ['Hexágono', 'Octágono']},
    'Octágono': {'aristas': 8, 'vecinos': ['Heptágono']}
}
